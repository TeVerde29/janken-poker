Política de Privacidad y Términos

Última actualización: 2 de noviembre de 2026

1. Arquitectura P2P y Datos del Usuario

JANKEN — The Card Duel es un juego web multijugador estático de código abierto. Todo el intercambio de jugadas entre los dos duelistas ocurre de forma directa de navegador a navegador mediante WebRTC (a través de PeerJS).

No poseemos servidores centrales de bases de datos, no almacenamos historiales de partidas en la nube, ni registramos cuentas de usuario.

2. Almacenamiento Local (localStorage)

El único dato que la aplicación guarda en tu dispositivo es:

  • Nombre del duelista (nickname): Se guarda localmente en el navegador para que no tengas que escribirlo cada vez que entres.
  • Preferencias técnicas: Estado de silencio del sintetizador de sonido Web Audio y estado de visualización del banner de instalación PWA en sessionStorage.

Ninguno de estos datos se envía a servidores de terceros con fines publicitarios o de telemetría.

3. Conexión de Red y Señalización

Para emparejar a los dos jugadores mediante el código de sala de 6 caracteres, la biblioteca PeerJS contacta temporalmente un servidor de señalización de código abierto únicamente para establecer el apretón de manos inicial (handshake WebRTC). Una vez establecida la conexión P2P entre ambos dispositivos, los mensajes de juego viajan directamente entre ellos.

4. Cookies y Rastreo

Este sitio no utiliza cookies analíticas, píxeles de seguimiento ni herramientas de publicidad de terceros. Es un proyecto de juego limpio y transparente.

5. Código Abierto y Contacto

El código fuente completo es público y auditable en GitHub. Para cualquier duda, reporte de seguridad o sugerencia, puedes abrir una incidencia en nuestro repositorio oficial.
